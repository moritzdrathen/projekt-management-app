# Project Guidelines

## Context
This is a university assignment (IU Internationale Hochschule, course 
DLBITOWAWBI01). The solution must reflect the complexity and style of a 
student project, not a production system. Keep it simple, readable, and 
explainable.

## Stack
- Backend: Spring Boot (Java), Spring Security with JWT, Spring Data JPA, 
  H2 file-based
- Frontend: React + TypeScript, Axios
- Build: Maven

## Constraints
- No over-engineering: no microservices, no Docker, no CI/CD pipelines
- No external services or cloud dependencies
- Code must be understandable by a CS student — avoid obscure patterns
- Comments in German where helpful for documentation purposes
- Complexity level matches what the IU coursebook (DLBITOWAWBI01) teaches
